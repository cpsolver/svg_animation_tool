documentation-in-unused-phrase:
Purpose: Get timestamps from the VTT (closed-caption) file, and
insert them into a copy of the script as desired-timestamp directives.
That script copy can be compared to the actual script using Meld
(or equivalent), and manually the appropriate times can be inserted
into the script, which controls when the keyframe transitions occur.
