reminders-about-skip-count-numbers-begin
0 (zero) omits all SVG files, but does all calculations and writes output files.
5 is a useful number for developing animation and timing.
9 provides greater resolution of animation motions.
99 is typical for final rendering.
Reminder: Large number omits duplicate SVG files during freeze segments.
If no number specified, writes duplicate SVG files during freeze segments,
which wastes time and resources if using render_svg_files_to_png program.
